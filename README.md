# ![emacs.d](pages/public/img/icon_192x192.png) emacs.d

## Emacs configuration to auto-format the following Programming Languages
* Rust
* Python
* PHP
* JavaScript
* Go
* AHK
* Kotlin
* Bash
* C


## Requirements 
* Install those programs what the emacs wrapper uses
```bash
	./requirement.sh
```
